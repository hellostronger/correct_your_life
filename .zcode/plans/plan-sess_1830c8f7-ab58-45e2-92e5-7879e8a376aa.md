# 全系统时间升级为带时分秒的时间戳

## Context

上一轮银证转账录入暴露的问题：时刻信息（HH:MM:SS）没有正式字段，被塞进备注或直接丢弃；前端约 40 处显示时把秒截掉（其中 8 处直接截 UTC 串，有 8 小时时区坑）。摸底结论：

- **存储层大部分已带秒**：新闻/社媒/聊天/模拟盘 created_at 等都是 TIMESTAMPTZ；
- **真正缺时刻的是手工台账**：`broker_cash` 侧车（date 只到日）、`sa_trades.trade_date`（DATE 列）；
- **有 ~15 处交易逻辑靠「日相等」比较**（T+1、同日反向闸门、幂等键、快照基准日归属），date 列改时间戳后必须逐处加日期截断，否则静默失效。

用户已明确裁决（AskUserQuestion 两题）：① sa_trades 加成交时刻；② **日期列整体升级为完整时间戳**（已知风险，接受）。两题合并实现：成交时刻直接折叠进升级后的 trade_date 时间戳列，不再单独建 trade_time 列。

## 口径总表（本次改什么、不改什么）

**升级为完整时间戳 `YYYY-MM-DD HH:MM:SS`（事件时刻类）：**

| 对象 | 现状 | 升级后 |
|---|---|---|
| `broker_cash` 侧车 `date` | `YYYY-MM-DD`，时刻在备注 | `YYYY-MM-DD HH:MM:SS`；迁移脚本从 54 条备注尾部解析时刻回填 |
| `sa_trades.trade_date`（PG DATE） | 只到日 | TIMESTAMP，新录入带真实成交时刻；旧行迁为 `00:00:00`（诚实表示"当时没记时刻"） |
| `sa_paper_trades.trade_date` / `settle_date`（PG DATE） | 决策日/结算日 | TIMESTAMP；**迁移用 `trade_date::timestamp + COALESCE(created_at::time, 00:00)`**——模拟盘决策本来就有精确时刻（created_at），回填真实时刻不是编造 |
| `sa_paper_cycles.trade_date`（PG DATE） | 轮次日 | TIMESTAMP `HH:MM:00`（由 date+slot 确定性推导，不用 now()，保证 ON CONFLICT 幂等） |
| `sa_paper_strategy_exits.exit_date`（PG DATE） | 影子卖出日 | TIMESTAMP（写入口用 now，读取窗口 SQL 加日期截断） |

**保持日粒度（明确不动，它们是"一天"的概念不是"一刻"）：**
- 基准日类：`account_anchors.asof_date`、`trade_snapshots.date`/`price_date`（快照对比的"不动日"，日K取价天然按日）
- 日频数据表主键日期：K线/估值/宏观利率/ETF流/指数成分/板块快照/`sa_paper_equity`
- `sa_calendar_events.event_date`（已有 time_hint 列）、上市日/报告期/提款截止日、`sa_t_advisory_log`（已有 created_at）
- `slot` 轮次标签（'HH:MM' 语义标签，非时间戳列）

**核心保护模式**：所有"日相等/日边界"比较统一改为 `trade_date::date = %s::date`（SQL）/ `str(v)[:10]`（Python），语义与升级前逐字节一致。

## Phase 4 — 模拟盘三表升级（风险最高，逐处 ::date）

## Phase 5 — PG 幂等迁移（启动时执行一次）

`app.py` init_db 后新增 `_migrate_ts_columns(conn)`：查 `information_schema.columns`，仅当列仍为 `date` 类型时执行：
```sql
ALTER TABLE sa_trades       ALTER COLUMN trade_date  TYPE timestamp USING trade_date::timestamp;
ALTER TABLE sa_paper_trades ALTER COLUMN trade_date  TYPE timestamp USING trade_date::timestamp + COALESCE(created_at::time, time '00:00:00');
ALTER TABLE sa_paper_trades ALTER COLUMN settle_date TYPE timestamp USING settle_date::timestamp + COALESCE(created_at::time, time '00:00:00');
ALTER TABLE sa_paper_cycles ALTER COLUMN trade_date  TYPE timestamp USING trade_date::timestamp + ...slot 推导秒;
ALTER TABLE sa_paper_strategy_exits ALTER COLUMN exit_date TYPE timestamp USING exit_date::timestamp + COALESCE(created_at::time, ...);
```
（sa_trades 旧行落 00:00:00；模拟盘行用 created_at 回填真实决策时刻。）迁移前对四张表 `CREATE TABLE ..._bak_YYYYMMDD AS SELECT *` 留回滚底；幂等（第二次启动见 timestamp 类型即跳过）。

## 不做 / 已否决

- 不改基准日/日频表/日历 event_date（见口径总表）；不建独立 trade_time 列（时刻折叠进 timestamp 主列）；不追 `datetime-local` 控件（沿用 date+time 双输入合并）。

- 侧车：迁移前 `.bak` 备份，直接还原；
